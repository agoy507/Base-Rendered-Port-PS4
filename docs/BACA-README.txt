Harvest Moon: Back to Nature - MOD by Penyu V1.3.0 (Edisi Emulator PS1)

ID:
- Mainkan file .cue di emulator PS1 (DuckStation, ePSXe, PCSX-ReARMed, RetroArch, AetherSX/
  dll). Pakai BIOS PS1 asli (mis. SCPH-1001) agar kartu memori/save diary berjalan normal.
- Isi: terjemahan + fitur mod yang muat di memori PS1, ditambah SPRINKLER:
  * Saibara menjual Sprinkler Bronze (7.500G), Perak (15.000G), Emas (30.000G) sejak awal
    (menu "Bl. Alat"), tanpa event Claire/Thomas.
  * Pegang sprinkler, tombol KOTAK memasang di petak ladang di depan, X mengambil kembali.
    Di ladang tampil seperti ikon di tas (tanpa animasi). Tiap pagi menyiram 3x3 di sekelilingnya (Perak 2 area, Emas 4 area). Di luar libur
    musim dingin; di rumah kaca sepanjang tahun.
- Fitur khusus versi PC/Android (Claire, toko baju Jeff, kotak baju, anjing ikut, kapal,
  layar lebar, save state) TIDAK ada di edisi ini.
- Save diary edisi ini terpisah dari versi PC/Android (format data mod berbeda); jangan
  dicampur.

EN:
- Play the .cue in a PS1 emulator with a real PS1 BIOS.
- Saibara sells the Bronze/Silver/Gold sprinklers (7,500/15,000/30,000G) from the start.
  Hold one: SQUARE sets it on the field tile in front, X takes it back; each morning it
  waters the 3x3 around it (Silver 2 areas, Gold 4).
- The PC/Android-only features are not in this edition.
